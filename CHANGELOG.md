# Changelog

## 0.1.0 (2026-11-10)

First public release.

- Quick notes from Alt+Q or a held middle mouse button, stickies from Alt+W, the deck from Alt+Shift+Q
- Notes are Markdown files in a folder you choose, with reminders (`@15:00`, `@fri`) and `#tag` routing
- Stickies that float, sit on the desktop, or follow one app
- Sort: files waiting notes into your library through Claude Code, Codex, Gemini CLI, an API key, Ollama, LM Studio or your own server, after checking every path
- Send by hand to Obsidian, Logseq, a Markdown folder, Joplin, Anytype, Notion, Todoist or Tana
- Optional `tuck` skill for coding agents
- Unsigned per-user installer; see the README about SmartScreen
